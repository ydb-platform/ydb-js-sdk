# Безопасность в Query

Основные рекомендации по безопасности YQL‑запросов в `@ydbjs/query`.

## Инъекции и параметры

- Передавайте значения отдельно от SQL: через шаблон `sql\`... ${value} ...\``или объект параметров`session.execute(text, parameters)`.
- Не конкатенируйте пользовательский ввод в строку запроса.

```ts
await sql`SELECT * FROM users WHERE id = ${userId}` // безопасно
```

## Динамические идентификаторы

- Для имён таблиц/колонок используйте `identifier(name)`.
- Для доверенных фрагментов — `unsafe(sql)`, не передавайте туда пользовательский ввод.

## Null/undefined

- Для отсутствующего значения с известным типом используйте `Optional` из `@ydbjs/value/optional`, например `new Optional(null, new Int32Type())`.
- Шаблон отклоняет обычные `null` и `undefined`; `null` в именованном параметре обозначает YDB `Null`, а не Optional с известным типом.
- `.parameter(name, undefined)` удаляет привязку; `undefined` в объекте параметров `execute()` отклоняется.

## Лимиты и валидация

- Ограничивайте значения `LIMIT/OFFSET`, валидируйте все входные данные.
